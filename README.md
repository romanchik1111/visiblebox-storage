# VisibleBox storage

Собственная служебная HTTPS-страница для настроек VisibleBox. Она не использует файлы, серверы или пространство имён QOLock.

Адрес: https://romanchik1111.github.io/visiblebox-storage/bridge.html

Страница хранит только дальность, толщину и два RGB-цвета в localStorage встроенного браузера игрока. Серверной базы настроек, авторизации Steam, аналитики и внешних скриптов нет. Параметры передаются фрагментом URL; обычный HTTP-запрос его не содержит. Провайдер получает обычные сетевые метаданные, включая IP.

Порядок запуска: загрузка базового адреса → PAGE_LOADED → hello → READY с совпадающим nonce → чтение или запись. В игре предусмотрены три ограниченные попытки по 20 секунд. Подтверждение записи отправляется только после чтения записанного значения обратно.

Обе стороны проверяют полную схему четырёх параметров, диапазоны, цвета и ревизию. Начальная ссылка с командой сохранения ничего не записывает. Страница отказывается работать внутри iframe. Meta-CSP разрешает только точный SHA-256 нашего скрипта, запрещает внешние соединения, формы, изображения и workers. GitHub Pages не выдаёт наш собственный HTTP frame-ancestors: это ограничение хостинга, iframe guard реализован в коде страницы.

localStorage разделяется по браузерному профилю и origin, а не по Steam-аккаунту. Друзья на разных компьютерах имеют разные настройки. Очистка профиля может удалить сохранение. Другие страницы на том же origin владельца потенциально имеют доступ к тому же localStorage: не размещайте на нём недоверенные приложения.

Сохранение и восстановление подтверждены на опубликованной странице в двух отдельных процессах Edge с обычной проверкой TLS. Игровой тест Steam CEF выполняется отдельно. Для первоначальной загрузки страницы нужен Интернет.

Абсолютная неуязвимость не обещается. Захват аккаунта хостинга может привести к замене кода; защищайте аккаунт и проверяйте публикуемые изменения. В репозитории находятся только наши статические файлы. Игровые VPK, конфиги, ключи и пользовательские настройки здесь не публикуются.
